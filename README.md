# ☕ Tarea 3 - Big Data UNAD: Procesamiento del Café Colombiano

## 📌 Descripción del Proyecto

Este repositorio contiene el desarrollo de la **Tarea 3 del curso Big Data** de la Universidad Nacional Abierta y a Distancia (UNAD), correspondiente al **Resultado de Aprendizaje RAC 2**: *Diseñar e implementar soluciones de almacenamiento y procesamiento de grandes volúmenes de datos utilizando herramientas como Hadoop, Spark y Kafka.*

El proyecto aborda el análisis de datos del **café colombiano**, uno de los productos agrícolas más representativos del país, aplicando técnicas de procesamiento en **batch** con Apache Spark y procesamiento en **tiempo real** con Apache Kafka + Spark Streaming.

## 🎯 Objetivos

- Analizar históricamente la producción y comercialización del café colombiano por departamento, variedad y calidad.
- Implementar un pipeline de streaming que monitoree transacciones cafeteras en tiempo real.
- Aplicar buenas prácticas de ingeniería de datos con DataFrames de Spark.

## 📊 Dataset Utilizado

- **Nombre:** Café Colombiano - Producción y Comercialización
- **Fuente:** Inspirado en estadísticas de Fedecafé y Banco de la República
- **Volumen:** 5,000+ registros
- **Variables clave:** departamento, municipio, variedad, cantidad_kg, precio_carga, calidad, comprador
